# Evidence Placement

Decide this ledger with the author at skeleton stage. There is no global quota for main-text evidence.

| Result, control, or limitation | Claim supported | Destination | Load-bearing? | Placement rationale |
|---|---|---|---|---|
| [ITEM] | [CLAIM] | Main / Methods / Extended Data / Supplementary Information / Omit | yes / no | [ONE SENTENCE] |

A test is load-bearing when it changes the sign, magnitude, mechanism, scope, or credibility of the central claim. Keep such evidence in the main narrative; place supporting checks where they remain available without breaking the argument.
