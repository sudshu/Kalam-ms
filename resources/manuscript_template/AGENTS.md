# Kalam manuscript

This folder is a manuscript managed by the **Kalam** agent framework. The full
workflow, skills, and conventions are maintained once at the framework root — do
not duplicate them here.

**Start here:**
1. **`../../AGENTS.md`** — the Kalam agent spec: the 3-stage workflow
   (ideation → skeleton → full manuscript), the `/km-*` skills table, build/export
   commands, and figure/citation/platform conventions.
2. **`metadata.yaml`** (this folder) — this manuscript's title, authors, target
   journal, `journal_profile`, `stage`, `current_draft`, and `analysis_dir`.
3. **`notes.md`** (this folder) — manuscript-specific decisions and context.

To change agent behavior for every manuscript, edit `../../AGENTS.md`, not this
file, so all manuscripts stay in sync.
