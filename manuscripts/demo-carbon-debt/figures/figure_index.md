# Figure index — demo-carbon-debt

All figures are regenerated by `figures/make_demo_figures.py` (requires matplotlib and
numpy). Every plotted value comes from that script's `RESULTS` dictionary, which mirrors
the numbers in `drafts/main_text.md`, so the figures cannot silently drift from the text.

| # | File | Carries | Cited in |
|---|---|---|---|
| 1 | `main/figure1_design_and_trajectories.pdf` | Paired design; carbon trajectories; flux recovery | main_text Results |
| 2 | `main/figure2_carbon_debt.pdf` | Per-site debt; placebo test; process attribution | main_text Results |
| S1 | `si/figureS1_robustness.pdf` | Threshold and numerical sensitivity | extended_data_SI |

## Conventions followed

Per `resources/conventions/figures.md`: vector PDF only, no rasterized panels, fonts
embedded as TrueType (`pdf.fonttype = 42`) so caption text stays selectable, tick labels
at 9 pt and axis labels at 10 pt, panel letters lowercase and left-aligned.

## Regenerate

```bash
python figures/make_demo_figures.py
```

The script prints a warning if the synthetic ensemble spread stops reproducing the 73%
positive-debt fraction quoted in the text.
